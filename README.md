
# College Placement Management System

A web-based College Placement Management System that simplifies student registration, company management, placement opportunities and job application tracking.

## Problem Statement

Manual placement activities make it difficult to maintain student records, manage company details, verify eligibility and track applications.

This project provides a centralized web platform to organize and simplify college placement activities.

## Objectives

- Maintain student academic information.
- Manage company details.
- Display placement opportunities.
- Check student eligibility based on CGPA.
- Allow students to apply for jobs.
- Track placement applications.
- Provide an administrator dashboard.

## Features

### Student Module
- Student registration.
- Student login.
- Student profile.
- CGPA details.
- Company listings.
- Eligibility checking.
- Job application tracking.

### Admin Module
- Administrator login.
- Dashboard statistics.
- View registered students.
- Add placement drives.
- Delete placement drives.
- View placement reports.
